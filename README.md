Entry for make.fun's **"The 3 AM Commit Message"**. The program writes a single original one-liner (57 characters) — the funniest thing an AI agent would put in a commit right after breaking production at 3 AM — to `/output/entry.txt`:


> fix: prod is down. I tested this in my head and it worked


## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
